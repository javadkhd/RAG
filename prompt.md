---

# Project Goal

Build a reusable RAG Platform that allows users to create independent RAG systems for different projects.

Each project should have:

- Its own workspace
- Its own datasets
- Its own documents
- Its own embeddings
- Its own retrieval configuration
- Its own conversation/task memory

The final system should allow:

1. Uploading project-specific knowledge sources.
2. Indexing the data.
3. Asking questions against that knowledge base.
4. Receiving answers generated by an LLM.
5. Easily changing LLM providers.
6. Easily adding new data sources.
7. Sharing the platform with other developers.

This is NOT a single-purpose RAG application.

This must be designed as a reusable RAG Framework / Platform.
